## Padrão adotado para novos projetos
Para cada novo trabalho/disciplina:
- criar uma pasta própria
- incluir `README.md` com objetivo e instruções
- incluir `requirements.txt` com dependências
- incluir arquivos finais de entrega (`.ipynb`, `.pdf`, etc.)
