## Padrao adotado para novos projetos
Para cada novo trabalho/disciplina:
- criar uma pasta propria
- incluir `README.md` com objetivo e instrucoes
- incluir dependencias e configuracao de execucao
- incluir arquivos finais de entrega (`.ipynb`, `.pdf`, etc.)
